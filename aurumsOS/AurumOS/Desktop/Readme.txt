AurumOS desktop

Move or copy a ComputerCraft program into /x32/Desktop to show it here.
Double-click an item to open it in a window.
Use the bottom taskbar to focus, minimize, restore, or close windows.
Use Share to send files/text over RedNet.
Use Settings to change gradient, icon size, and monitor scale when supported.
Settings can also set an optional login password.
Use Sheets, Code Studio, Clock, and BIOS from the desktop or Start menu.
Use Tiny Market for apps/updates and Turtle Remote with turtle_client.lua.
Drag desktop icons to Trash to remove them.
